# 🧮 Casio C-80 JavaFX Calculator

<img width="398" height="478" alt="image" src="https://github.com/user-attachments/assets/6c00b578-c3fb-430e-b3d9-59afe67b715a" />


A retro desktop calculator inspired by the classic **Casio C-80**, developed using Java 21, JavaFX, and custom CSS stylesheets to emulate a vintage LCD screen.

## 🚀 Features
- Retro LCD-style design with resin buttons and visual feedback.
- Precise navigation and input with the cursor (`<` and `>`).
- Basic mathematical operations (`+`, `-`, `*`, `/`).
- Built using **MVC** architecture with JavaFX + FXML.

## 🛠️ Technologies Used
- **Java**: 21
- **JavaFX**: 21.0.6
- **Build Tool**: Maven
